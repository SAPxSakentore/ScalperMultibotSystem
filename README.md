# KazBuildOS 🏗️

**Система автоматизации сопровождения промышленных строительных проектов Республики Казахстан**

> Специализация: Магистральные газопроводы высокого давления и другие объекты промышленного строительства

---

## О системе

KazBuildOS — это платформа виртуальной строительной компании с AI-агентами (на базе Claude), которая автоматизирует полный цикл сопровождения строительного проекта:

```
Инициация → Проектирование → Согласования → Закупки → Строительство → Испытания → Приемка
```

### Ключевые возможности

- **9 AI-агентов** — виртуальные сотрудники (ГИП, Главный инженер, ОТК, ОТ и ПБ, Сметчик, Юрист, Прораб)
- **Автогенерация ИТД** — ОЖР, АОСР, Акты испытаний, КС-11/14 в формате DOCX
- **Нормативная база РК** — СП РК 2.04-103-2013*, СП РК 1.04.02-2019, СНиП РК 3.01.01-2008* и др.
- **Офлайн-режим** — SQLite + PWA Service Worker
- **PWA** — работает как мобильное приложение

## Быстрый старт

### 1. Клонировать и настроить

```bash
git clone <repo>
cd ScalperMultibotSystem

# Создать .env из примера
cp .env.example .env
# Отредактировать .env — добавить ANTHROPIC_API_KEY
```

### 2. Запуск через Docker Compose

```bash
docker-compose up -d
```

- **Frontend PWA**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Docs**: http://localhost:8000/api/docs

### 3. Запуск для разработки

**Backend:**
```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

## API Endpoints

### Проекты
- `GET /api/projects` — список проектов
- `POST /api/projects` — создать проект
- `GET /api/projects/{id}/itd-checklist` — чеклист ИТД
- `POST /api/projects/{id}/generate-plan` — сгенерировать план (ГИП)
- `POST /api/projects/{id}/analyze-risks` — анализ рисков (ГИП)

### Документы
- `POST /api/documents/generate/ojr` — создать ОЖР
- `POST /api/documents/generate/aosr` — создать АОСР
- `POST /api/documents/generate/hydraulic-test` — акт испытаний
- `POST /api/documents/generate/ks11` — создать КС-11
- `GET /api/documents/{id}/download` — скачать DOCX

### Агенты
- `GET /api/agents` — список агентов
- `POST /api/agents/{role}/chat` — чат с агентом
- `GET /api/normatives` — нормативная база

## Оффлайн режим

При отсутствии интернета:
- **База данных**: SQLite работает полностью локально
- **AI-агенты**: переходят в режим заглушки (скриптовые ответы)
- **PWA**: кэширует UI и данные через Service Worker
- **DOCX**: генерация документов работает без сети

Для включения оффлайн режима: `OFFLINE_MODE=true` в `.env`
